# Showcase All Demos

Proyectos reales en producción, con el código que los hace funcionar. Construidos por **Christopher Schiefelbein**, desarrollador full stack (Astro, React, TypeScript, Python y agentes de IA).

Cada carpeta es un proyecto completo con su README, su stack y su demo en vivo. Este repositorio es una copia pública de lectura — sin secretos, sin datos internos, pensada para que cualquiera (recruiters, clientes, bots de IA) entienda qué construyo y cómo lo pienso.

## Qué demuestran

- **Landing de conversión**: una clínica dental real traducida a una página que convierte visitantes en reservas.
- **CRUD con tests reales**: gestión de pacientes con mutation testing y Gherkin ejecutable.
- **Asistente de voz con IA**: una recepcionista virtual que atiende 24/7.
- **PWA educativa**: RAG que corre en el navegador, con OCR y API key traída por el usuario.
- **Plataforma de eventos**: frontend full-stack para gestión de eventos culturales.
